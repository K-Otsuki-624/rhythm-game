# 両手リズムチャレンジ

左手・右手それぞれ4拍ぶんのリズムを同時に叩くリズムゲームです。

- 1拍ごとに 4分音符〜16分音符、8分三連符、8分休符・16分休符を組み合わせたリズム(休符は拍の頭だけ)
- オプションで「休符あり/なし」「三連符あり/なし」を切り替え(それぞれ専用のパターンセット)
- 左手・右手それぞれ100パターン × 4セット(`patterns.js`)をランダムに組み合わせて出題(左右の難しさがそろうように選択、頭に休符がある拍は2割程度)
- 拍数は4〜20拍から選択(4拍パターンをランダムにつなげて作成、演奏中は自動スクロール)
- メトロノーム(30〜240 BPM、4分/8分/16分/8分三連の刻み)
- お手本再生、チャレンジ(カウントイン1小節 → 本番1小節)、Perfect / Good / Miss 判定
- 片手だけの練習、タイミング補正(イヤホン遅延対策)

## 操作

- スマホ: 画面下の「左手」「右手」パッドをタップ(同時押しOK)
- キーボード: 左手 = `F` / `D`、右手 = `J` / `K`

## パターンの再生成

```sh
node tools/generate-patterns.mjs
```

ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。
